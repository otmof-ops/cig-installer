# Error codes

Every error `ciginstaller` prints carries a stable code and the area it comes from, rendered as `error[E1811 carton]: ...`, and every code is an entry in one registry (`errors/registry.toml`): its family, which of the **four kinds of no** it is, what it means, what to type next, and its ranked causes, each with the read-only probe the doctor uses to confirm it and the remedy. `ciginstaller explain <code>` prints the same page at the terminal, and `ciginstaller explain` with no code lists them all. The installer's codes are `E1800` to `E1899`; the other products' codes are in their own references.

A code never changes meaning. A retired code is never reused. A code marked *planned* is reported by another tool, once that tool calls the installer's check. This page is generated by `cargo xtask errors-doc`; do not edit it by hand. A test fails when it is out of date.

## Ranges

| codes | family | rendered as | meaning |
|---|---|---|---|
| `E1800`–`E1819` | installer | `usage` | the installer: carton and tool combinations that do not fit (marry-up), and cartons, channels, packs and tools that do not exist |
| `E1820`–`E1839` | installer | `runtime` | the installer: fetching and trusting artifacts, the store, toolchains and transactions |
| `E1840`–`E1879` | installer | `usage` | the installer: shims, pins, updates, rollbacks, repair, uninstall, and the command line |
| `E1880`–`E1889` | installer | `runtime` | reserved for CIG.OS work not built yet: Secure Boot (#23) takes E1880-E1883, the courier (#24) E1884-E1888 |
| `E1890`–`E1899` | installer | `internal` | internal: a bug in the installer, or a journal it cannot recover |
| `E1900`–`E1999` | installer | `usage` | the installer, second range: the mirror and what travels over it (E1900), the update channel's signatures (E1901), what a shim refuses to run and why (E1902, E1903), and the settings the machine locks (E1904); the rest is not assigned yet |

## The four kinds of no

| id | what you hear | whose problem | the manual's name |
|---|---|---|---|
| `none` | not one of the four | a mistake in the text, in the arithmetic, or in CigScript | syntax, type or logic error; an internal error |
| `cant-see-any` | can't see any ciggies bro | yours: you're pointed at the wrong place | wrong address: a path, a name, a directory not on PATH; ENOENT |
| `never-heard-of-you` | never heard of you | the door: it doesn't know you | 401 Unauthorized; authentication failure |
| `these-are-mine` | these are MY ciggies | the door: it knows you and said no | 403 Forbidden; permission denied; a lock; a refusal by policy |
| `dont-have-any` | don't have any over here | nobody's: right place, right you, nothing there | 404 from the server's side; an empty result |
| `depends` | one of the four; the message says which | read the operating-system reason in the message | ENOENT, EACCES, ENOSPC and friends, each mapped in the causes below |

### E1800 combination refused

*usage · since 0.1.0 · arises in any*

**Kind of no:** these are MY ciggies (the door: it knows you and said no; 403 Forbidden; permission denied; a lock; a refusal by policy).

The carton, sticks and project pins you asked for do not fit together, and a more specific rule has not named the reason. Nothing was changed.

**What to type next:** `ciginstaller check`

**Known causes**, ranked; the doctor checks them in this order:

1. two products in the combination refuse each other (probe `manifest-cache`). **Remedy:** `ciginstaller check` names the pair; pick a carton that holds both: `ciginstaller carton list`
2. a project pin conflicts with the installed carton (probe `project-pins`). **Remedy:** `ciginstaller check --project <dir>`, then `ciginstaller pin carton <pin>`

Related: [`E1801`](#e1801-a-product-needs-another), [`E1802`](#e1802-a-stick-does-not-fit-its-carton).

### E1801 a product needs another

*usage · since 0.1.0 · arises in any*

**Kind of no:** these are MY ciggies (the door: it knows you and said no; 403 Forbidden; permission denied; a lock; a refusal by policy).

One product in the combination needs a version of another that is not there, for example cigo needs a cig at or above its minimum. A hard requirement leads with "these two don't smoke together." and refuses, with the fix as one command; a soft one only warns.

**What to type next:** `ciginstaller update` to the carton where they match, or keep the older tool for this project: `ciginstaller pin <tool> <version>`, for example `ciginstaller pin cigo 1.3`

**Known causes**, ranked; the doctor checks them in this order:

1. the project pins a cig older than the cigo in the carton accepts (probe `project-pins`). **Remedy:** `ciginstaller check`, then keep the tool that fits this project (`ciginstaller pin cigo 1.3`) or move to a carton where they match (`ciginstaller update`)
2. a stick replaced one product with a build the others do not accept (probe `installed-cartons`). **Remedy:** `ciginstaller check`, then `ciginstaller install carton` to put the carton's own build back

Related: [`E1800`](#e1800-combination-refused).

### E1803 yanked version or carton in use

*usage · since 0.1.0 · arises in any*

**Kind of no:** these are MY ciggies (the door: it knows you and said no; 403 Forbidden; permission denied; a lock; a refusal by policy).

A version or carton that its maintainers withdrew is installed or about to be. This is a warning; the machine keeps working.

**What to type next:** `ciginstaller update`

**Known causes**, ranked; the doctor checks them in this order:

1. the installed carton was yanked after you installed it (probe `manifest-cache`). **Remedy:** `ciginstaller update` moves to the newest carton that is not yanked
2. a project pins a yanked carton (probe `project-pins`). **Remedy:** `ciginstaller pin carton <pin>` with a carton that is not yanked

Related: [`E1804`](#e1804-security-advisory).

### E1804 security advisory

*usage · since 0.1.0 · arises in any*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

The manifest carries an advisory for a version you have installed. Shown once per version.

**What to type next:** `ciginstaller update`

**Known causes**, ranked; the doctor checks them in this order:

1. an advisory in the manifest names an installed build (probe `manifest-cache`). **Remedy:** `ciginstaller update` installs the carton that fixes it; `ciginstaller carton show <version>` lists the advisory

Related: [`E1803`](#e1803-yanked-version-or-carton-in-use).

### E1809 a script's pin is not met

*usage · since 0.1.0 · arises in run*

**Kind of no:** these are MY ciggies (the door: it knows you and said no; 403 Forbidden; permission denied; a lock; a refusal by policy).

A script pins the cig it was written for in its header (`# cig >=1.6.2`), and no cig installed here meets that pin. The resolver tried the carton the project or the machine uses, then every installed cig, and fetching a carton that has one was off or is not possible: `which` never fetches, `pin_fetch` was `never` or `ask` with nobody to ask, or no carton on the channel has a cig that meets it.

**What to type next:** `ciginstaller install carton --carton <version>` (the message names the carton), or `ciginstaller carton list`

**Known causes**, ranked; the doctor checks them in this order:

1. the carton that has a cig new enough is on the channel but not installed, and fetching is off (probe `installed-cartons`). **Remedy:** `ciginstaller install carton --carton <version>`, then run the script again; `ciginstaller config set pin_fetch auto` lets the shim do it
2. no carton on this channel has a cig that meets the header, because the pin asks for a cig newer than any shipped or for another major version (probe `carton-list`). **Remedy:** `ciginstaller carton list` shows each carton's cig; loosen the header, or `ciginstaller channel beta` if a newer cig is there
3. the header holds a typo, such as `>=1.62` for `>=1.6.2` (probe `pin-file`). **Remedy:** `ciginstaller which cig --why --script <file>` shows what was asked for and how far the look got

Related: [`E1801`](#e1801-a-product-needs-another), [`E1842`](#e1842-pinned-carton-unavailable-and-fetching-refused).

### E1810 no manifest

*usage · since 0.1.0 · arises in any*

**Kind of no:** don't have any over here (nobody's: right place, right you, nothing there; 404 from the server's side; an empty result).

The installer has no manifest to work from: it is offline and the cache is empty, or the channel returned nothing.

**What to type next:** `ciginstaller update --check`, online, to fetch the manifest

**Known causes**, ranked; the doctor checks them in this order:

1. offline, with no cached manifest for the channel (probe `manifest-cache`). **Remedy:** connect, then run `ciginstaller update --check`
2. the cache directory was removed or never written (probe `state-dir-writable`). **Remedy:** `ciginstaller update --check` rebuilds it

Related: [`E1873`](#e1873-offline-was-requested-and-the-step-needs-the-network), [`E1812`](#e1812-no-such-channel).

### E1818 carton lacks a tool this machine has

*usage · since 0.1.0 · arises in any*

**Kind of no:** don't have any over here (nobody's: right place, right you, nothing there; 404 from the server's side; an empty result).

The carton named is meant to have a tool the machine's carton has (by the manifest), and its record here does not, so switching would leave that shim with nothing to run. A carton that does not have the tool at all is switched to with a warning instead.

**What to type next:** `ciginstaller install carton --carton <version>`

**Known causes**, ranked; the doctor checks them in this order:

1. the carton's record was made before the tool was added to it, or the tool was uninstalled (probe `installed-cartons`). **Remedy:** `ciginstaller install carton --carton <version>` fills the carton in

Related: [`E1817`](#e1817-carton-is-only-partly-installed), [`E1840`](#e1840-nothing-installed-for-this-tool).

### E1819 the channel's latest carton is not fetched

*usage · since 0.1.0 · arises in run*

**Kind of no:** don't have any over here (nobody's: right place, right you, nothing there; 404 from the server's side; an empty result).

Nothing is installed here and no project pin or machine carton says what to run, so the resolver's last step is the channel's latest carton. It was not fetched: `which` never fetches, `pin_fetch` was `never`, `--offline` was given, or `ask` had no terminal to ask on.

**What to type next:** `ciginstaller install carton`

**Known causes**, ranked; the doctor checks them in this order:

1. ciginstaller has not installed anything yet, and a shim or `which` was run first (probe `installed-cartons`). **Remedy:** `ciginstaller install carton`
2. the shim ran with no terminal and `pin_fetch` is `ask`, the default, which acts as `never` then (probe `manifest-cache`). **Remedy:** `ciginstaller install carton` once, or `ciginstaller config set pin_fetch auto` for CI

Related: [`E1840`](#e1840-nothing-installed-for-this-tool), [`E1842`](#e1842-pinned-carton-unavailable-and-fetching-refused).

### E1900 a mirror over plain http

*usage · since 0.1.0 · arises in update, doctor, any*

**Kind of no:** these are MY ciggies (the door: it knows you and said no; 403 Forbidden; permission denied; a lock; a refusal by policy).

A mirror is a plain `http://` address that is not on this machine, or it is on this machine and the build it served is not one a pin vouches for, or a download was sent on from https to http. Plain http proves nothing about the file, so it is refused: `https://` is accepted anywhere, `http://` only to a loopback address (127.0.0.1, ::1), and then only for builds this ciginstaller holds a pin for; `allow_single_source` does not change that. Nothing was downloaded into the store.

**What to type next:** `ciginstaller config set mirror https://<your mirror>/`, or `ciginstaller config unset mirror` to use GitHub

**Known causes**, ranked; the doctor checks them in this order:

1. the `mirror` setting (or CIGI_MIRROR) names an `http://` address that is not loopback (no probe; a suggestion, not a finding). **Remedy:** `ciginstaller config set mirror https://<your mirror>/`, or `ciginstaller config unset mirror`; `ciginstaller doctor` lists it
2. the mirror is plain http on this machine and the build it served is not one a pin vouches for (no probe; a suggestion, not a finding). **Remedy:** serve the mirror over https, or use a `file://` mirror or a bundle (`ciginstaller install carton --from <bundle>`)
3. a server answered an https request by sending it on to plain http (no probe; a suggestion, not a finding). **Remedy:** ask the mirror's operator to serve https only; nothing here can be told to follow it

Related: [`E1820`](#e1820-download-failed), [`E1822`](#e1822-trust-floor-not-met), [`E1838`](#e1838-mirror-directory-refused).

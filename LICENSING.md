Which version of cig-installer is under which license, in one table. The
[LICENSE](LICENSE) file is the text that governs the current code; this page
records the history and says where to ask for anything else.

|---|---|---|
| Commits `5571157` through `39a9b00` (31 commits, 2026-11-10); tagged `apache-2.0-last` | Apache-2.0 | No release or tag other than `apache-2.0-last`. Copies taken in this range stay under Apache-2.0. |

## The Apache-2.0 period

From its publication on 2026-11-10 until this licensing change was merged, the
repository was public under Apache-2.0, before it had a release. That grant is
permanent for any copy taken in that period; as measured on 2026-11-10, GitHub
recorded no forks, clones or views.

## Terms the license does not give

Jay Taylor holds the copyright and can license the code on other terms. To ask,
open an issue on [this repository](https://github.com/otmof-ops/cig-installer/issues)
saying what you want to do. Security problems go through the private reporting
described in [SECURITY.md](SECURITY.md), not an issue.

The name is covered separately by [TRADEMARKS.md](TRADEMARKS.md). Dependencies
keep their own licenses; see [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
